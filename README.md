# HR Data Analysis Dashboard — Excel

## 📌 Project Overview
The HR Data Analysis Dashboard is an Excel-based analytics project designed to analyze workforce data and provide meaningful HR insights. The dashboard helps organizations monitor employee attrition, hiring trends, workforce diversity, and department-wise performance through interactive visualizations.

This project demonstrates how Microsoft Excel can be used for business intelligence and HR analytics using PivotTables, PivotCharts, slicers, and KPI metrics.

---

## 🎯 Objectives
- Analyze employee attrition trends
- Track hiring and workforce growth
- Monitor gender diversity and department distribution
- Build an interactive HR dashboard
- Generate actionable HR insights for better decision-making
